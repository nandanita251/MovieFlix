# 🎬 MovieFlix – Movie Recommendation App

MovieFlix is a modern, responsive, and visually rich **movie & TV series recommendation web application** built using React.  
The app displays trending, popular, and top-rated content using live data fetched from an external movie database API.  
Its clean UI and streaming-platform-style design provide a premium OTT-like experience.

---

## 🚀 Features

### ⭐ Dynamic Hero Banner  
- Displays the top trending movie/series  
- Shows title, description, genres, and rating  
- High-quality background poster

### 🎞️ Popular Movies & Series  
- Auto-fetched from the API  
- Smooth horizontal scroll sliders  
- Attractive poster cards

### 🔍 Search Function  
- Live movie/series search  
- Fetches real-time results from API

### 🌙 Dark/Light Mode  
- One-click theme toggle  
- Modern UI with smooth transitions

### 🎭 Genre Tags & Ratings  
- Colorful categories (Action, Animation, etc.)  
- IMDb-style circular rating indicator

### 📱 Fully Responsive  
- Optimized for mobile, tablet, and desktop  
- Netflix-inspired layout

---

## 🛠️ Tech Stack

- **React.js**  
- **JavaScript (ES6+)**  
- **TMDB API** (or any movie API)
